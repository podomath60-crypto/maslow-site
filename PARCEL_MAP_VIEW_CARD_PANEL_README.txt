/parcel-map 지도 뷰 매물카드 패널 패치

수정 파일
- parcel-map/index.html

주요 변경
1. 지도 중앙하단에 현재 지도 화면 안에 들어온 매물 수 버튼 추가
   - 문구: 매물 N개
   - 지도 이동/줌 중에는 카드 렌더링하지 않고, idle 후 220ms debounce로 개수만 갱신

2. 버튼 클릭 시 오른쪽 패널에 현재 지도 뷰 안의 매물카드 렌더링
   - 제목: 현재 화면 매물 N개
   - 60개 초과 시 상위 60개만 표시하고 안내문 표시
   - 카드 DOM은 버튼 클릭 시에만 생성해서 지도 이동 중 부하 방지

3. 매물카드 동작 연결
   - 카드 본문 클릭: 지도 중심 이동 + 핀 선택 + 해당 매물 지정 PNU만 필지 폴리곤 조회
   - 보기: /listings?listingNumber=...&open=1 새창
   - 수정: /admin?listingNumber=... 이동
   - 상태: 기존 parcel-map 상태 모달
   - 메모: 기존 parcel-map 메모 모달
   - 공유: dashboard sharePreview 방식과 동일하게 navigator.share/clipboard/prompt 순서
   - 네이버지도: 네이버 지도 검색 새창
   - 땅야: 대표 PNU 또는 첫 PNU로 땅야 상세 새창
   - 보임/숨김: 기존 상태 API로 즉시 변경

4. 선택 상태 유지
   - 지도 핀 클릭 또는 카드 클릭 시 오른쪽 카드 목록에서 선택 카드만 펼쳐짐
   - 펼쳐진 카드에 필지정보/메모/상세 액션 표시

대시보드 원본은 수정하지 않음.
